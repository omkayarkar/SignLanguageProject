# \# Indian Sign Language Alphabet Recognition

# 

# A Python-based computer vision and machine learning project that recognizes trained hand-sign alphabet classes using a webcam. It uses MediaPipe Hands to extract hand landmarks and a Random Forest classifier to predict the corresponding label.

# 

# \## Features

# 

# \- Real-time webcam-based hand detection

# \- Hand landmark visualization using MediaPipe

# \- Machine learning classification with Random Forest

# \- Prediction smoothing using majority voting

# \- Dataset collection and model training scripts

# \- Indian Sign Language learning resources

# 

# \## Technologies Used

# 

# \- Python

# \- OpenCV

# \- MediaPipe

# \- NumPy

# \- Pandas

# \- scikit-learn

# \- Joblib
